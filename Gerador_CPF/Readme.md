# Gerador de CPF em Python

Projeto criado para gerar CPFs válidos de forma automática, seguindo as regras oficiais de cálculo dos dígitos verificadores.

O CPF gerado passa pelo mesmo algoritmo utilizado na validação oficial.

## Funcionalidades
- Geração automática dos 9 primeiros dígitos
- Cálculo dos dois dígitos verificadores
- Geração de CPF válido para testes

## Conceitos aplicados
- Biblioteca random
- Listas
- Laços de repetição
- Condicionais
- Lógica matemática

## Objetivo
Exercitar lógica de programação e compreensão de algoritmos utilizados em sistemas reais.

## Como rodar
Abrir o Terminal e executar o comando py gerador_cpf.py
