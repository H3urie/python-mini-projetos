# Lista de Compras em Python

Projeto simples desenvolvido em Python que simula uma lista de compras no terminal, utilizando conceitos de lógica de programação e operações básicas de CRUD (Create, Read, Update e Delete).

## Funcionalidades
- Inserir itens na lista
- Listar itens com índice
- Remover itens pelo índice
- Validação de entradas do usuário
- Interface via terminal

## Conceitos aplicados
- Estruturas de repetição
- Condicionais
- Listas
- Enumeração de listas
- Tratamento de erros (try/except)
- CRUD em memória

## Tecnologias
- Python 3

## Objetivo
Praticar lógica de programação em Python e consolidar conceitos fundamentais utilizados no desenvolvimento back-end.

## Como executar
```bash
python lista_compras.py
