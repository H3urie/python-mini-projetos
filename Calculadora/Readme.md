# Calculadora em Python

Uma calculadora simples feita em Python para prática de lógica de programação, condicionais, loops e tratamento de erros.

Funcionalidades
---
Soma

Subtração

Multiplicação

Divisão

Tratamento de erros para entradas inválidas

Laço contínuo com opção de sair

Conversão automática de tipos (int e float)

Tecnologias usadas
---
Python 3

Como usar
---
Execute o arquivo:
___
python calculadora.py
___
